This is a new minor release of the `@alextheman/components` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add a `Search` component.
  - This will help with entering and submitting search queries in applications.
  - It takes the raw state and a value to set it, and then the interpretation of the raw search state is up to the consumer in `handleSearch`.
  - Searches are submitted explicitly using the search button or by pressing Enter, rather than being triggered automatically whenever the search state changes.
  - This provides a more natural interaction for social-media-style applications such as Lexicon, while leaving the exact search behaviour up to the consumer.
