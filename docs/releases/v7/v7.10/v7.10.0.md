## Description of Changes

<!-- user-editable-section-start -->
- Add my personal logo as a SVG and React component.
  - The SVG is for internal use and is to be considered the source of truth for what my logo should be.
  - The exported `AlexTheManLogo` component is then the thing we can import into other projects. It lives in the `@alextheman/components/icons` entrypoint.

## Additional Notes

- The `AlexTheManLogo` component is derived from that by taking the raw SVG code and pasting it into [an SVG to JSX converter](https://svg2jsx.com/), dealing with any potential type errors as needed.
  - The one I have linked doesn't tend to cause too much - it's just a matter of removing an unrecognised inkscape property from the styles and renaming `ariaLabel` to `aria-label`.
