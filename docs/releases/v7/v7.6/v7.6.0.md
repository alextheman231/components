# v7.6.0 (Minor Release)

<!-- alex-c-line-release-status-start -->
**Status**: Released
<!-- alex-c-line-release-status-end -->

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `@alextheman/components` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Add the `undefinedFallback`, `nullFallback`, and `nullableFallback` to `QueryBoundaryData`, `QueryBoundaryDataMap`, and `QueryBoundaryValue`.
  - These components now own the rendering of loading, nullability, and data together, making nullability handling a built-in part of the data rendering flow.
  - It allows the data components to have full ownership over the entire data rendering flow, including the handling of nullable data.
- Deprecate `QueryBoundaryNullable` and `QueryBoundaryFallback`.
  - Use the `undefinedFallback`, `nullFallback`, and `nullableFallback` instead.
- Deprecate the `Error` and `Fallback` properties from the return of `createBaseQueryBoundary` for the same reasons as above.
