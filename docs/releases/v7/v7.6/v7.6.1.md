## Description of Changes

<!-- user-editable-section-start -->
- Allow the errorFallback to take a callback function that gives back the error
  - So that we can handle errors based on the actual error we get.
  - This was possible to do at runtime despite the type system not allowing it due to being left out by mistake. This allows it at the type-level too.
